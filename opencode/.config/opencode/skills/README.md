# Skills

Place global OpenCode skills here as `skills/<skill-name>/SKILL.md`.

Each `SKILL.md` must start with YAML frontmatter containing at least:

```md
---
name: skill-name
description: Short description of when to use this skill
---
```

Skill names must be lowercase alphanumeric with single hyphen separators and must match the containing directory name.

Do not add a skill until there is reusable behavior worth loading on demand.
